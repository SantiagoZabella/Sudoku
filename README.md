# Sudoku

Implementación de un generador y solutor de Sudokus en C.

## Funcionalidades

- Lectura de tableros desde archivos.
- Validación de filas, columnas y subcuadrados.
- Resolución mediante backtracking.
- Búsqueda de la primera casilla con menor cantidad de opciones.
- Detección de cantidad de soluciones.
- Generación de tableros con solución única.

## Compilación

make

## Ejecución

./sudoku archivo.txt
